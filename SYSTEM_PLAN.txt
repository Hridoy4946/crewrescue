1. EXECUTIVE SUMMARY & MISSION STATEMENT
--------------------------------------------------------------------------------
"Everything just changed. What should the organization do now?"

CrewRescue AI is an intelligent, emergency-resilient Field Service Management (FSM) 
and Workforce Optimization Platform designed specifically for mission-critical 
infrastructure operators.

Traditional FSM platforms (Salesforce Field Service, ServiceNow, ClickSoftware) 
excel at static scheduling under calm conditions, but catastrophically degrade 
when unexpected crises strike (storms, grid collapses, technician shortages). 
CrewRescue AI bridges this gap through:
  1. AI-assisted incident triage & NLP entity extraction
  2. Dynamic multi-objective heuristic re-optimization
  3. Explainable human-in-the-loop dispatch controls
  4. Real-time WebSocket telemetry across all mobile & web clients

--------------------------------------------------------------------------------
2. USER ACTORS & ROLE-BASED ACCESS CONTROL (RBAC)
--------------------------------------------------------------------------------
The system supports 11 distinct operational roles:

A. Human Actors:
  1. EMERGENCY_MANAGER   : Declares/resolves disaster levels (L0-L4), adjusts global
                           priority weights, triggers regional schedule overhauls.
  2. DISPATCHER          : Reviews incoming tickets, triggers optimization solver,
                           reviews Explainable AI reasoning, approves dispatch plans.
  3. FIELD_SUPERVISOR    : Monitors active crews, tracks live GPS coordinates, oversees
                           regional technician skill coverage.
  4. TECHNICIAN          : Receives work orders via mobile view/PWA, logs state 
                           transitions (ACCEPTED -> EN_ROUTE -> ARRIVED -> IN_PROGRESS 
                           -> RESOLVED), logs parts used and repair notes.
  5. OPERATIONS_DIRECTOR : Manages multi-tenant organization settings, depots, fleet,
                           user permissions, and overall SLA policies.
  6. AUDITOR / EXECUTIVE : Retrospective review of historical optimization runs,
                           SLA breach penalties, financial exposure, and audit logs.

B. Automated / System Actors:
  1. AI Triage Agent     : Ingests raw issue descriptions, predicts severity,
                           classifies categories, and extracts required skills & parts.
  2. Optimization Solver : Evaluates multi-objective cost functions across unassigned
                           tickets and technician capacities using heuristic solvers.
  3. Emergency Monitor   : Monitors incident surges & SLA breach thresholds; triggers
                           alerts across Socket.IO rooms.
  4. Real-Time Gateway   : Socket.IO WebSocket engine synchronizing live state.

4. MATHEMATICAL FORMULATION (OPTIMIZATION ENGINE)
--------------------------------------------------------------------------------
The scheduling solver minimizes the composite multi-objective cost function:

  Min Z = w1 * C_travel + w2 * C_sla + w3 * C_overtime + 
          w4 * C_criticality + w5 * C_unassigned + w6 * C_detour

Where:
  • w1 (0.20): C_travel      = Total transit travel time and fuel consumption
  • w2 (0.35): C_sla         = Financial penalty per minute of SLA deadline breach
  • w3 (0.10): C_overtime    = Overtime labor cost beyond scheduled shift hours
  • w4 (0.15): C_criticality = High-priority infrastructure weighting multiplier
  • w5 (0.15): C_unassigned  = Penalty for unresolved / unassigned incident tickets
  • w6 (0.05): C_detour      = Secondary travel time to depots for spare parts

Hard Operational Constraints:
  1. Skill Match: Skills(WorkOrder_i) ⊆ Skills(Technician_j)
  2. Immutability: Status IN ('EN_ROUTE', 'ARRIVED', 'IN_PROGRESS') cannot be moved
  3. Shift Limits: Total scheduled work <= Shift Duration + Max Allowed Overtime
